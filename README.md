# klipper-mmu documentation

This repository holds the published user documentation for **klipper-mmu**,
an optional add-on for Klipper that runs a multi-material unit's motion,
sensing and safety on the microcontroller wired to it.

Read it at **https://openamsorg.github.io/klipper-mmu-docs/**.

The site is plain static HTML with no build step. It is generated from the
klipper-mmu source repository and copied here; please report problems as
issues on this repository.

> **Safety:** nothing in klipper-mmu has been qualified on real MMU hardware
> yet. Read the "Read this first" section on the home page before flashing
> anything.
